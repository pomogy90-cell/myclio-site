# КЛИО — сайт салона красоты (myclio.ru)

Статик-HTML сайт + PWA (/app/) + модуль управления салоном. Прод: https://myclio.ru
Хостинг: Timeweb (shared, PHP 8.2, Apache), хранилище — JSON-файлы, без БД.

## Структура
- `index.html` — одностраничный сайт (услуги, цены, запись, отзывы)
- `app/` — PWA (клиентская часть); из копии `app/` собирается Android APK (проект сборки не входит в репозиторий)
- `admin/index.php` — мини-админка (заявки, цены, карточки, фото)
- `api/` — PHP-бэкенд: `lead.php` (заявки), `manage.php` (журнал записей), `fcm-push.php` (пуши), `dikidi-hook.php` / `dikidi-sync.php` (интеграция DIKIDI)
- `manage/` — модуль «Управление салоном» (общий для админки и приложения)
- `приёмка-md5.txt` — журнал приёмки версий с контрольными суммами

## Что намеренно НЕ в репозитории
- `api/data/` — живые данные и секреты (только на сервере)
- `img/`, `app/img/`, иконки — статичные изображения, копия всегда на https://myclio.ru/img/
- `app/klio.apk` — бинарник приложения (выдаётся файлом отдельно)
